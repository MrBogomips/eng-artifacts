# Definition of Done

## Requirements

- [ ] Structural tests pass: `bash tests/run-structural-tests.sh`
- [ ] Every OpenSpec change and spec validates: `openspec validate --all --strict`
- [ ] A change to the plugin's observable behavior went through an approved OpenSpec change, and that change is archived into `openspec/specs/` as the last commit before merge
- [ ] A change that affects appearance has a visual review with the verdict `pass`, or the person accepted the open items and each one is tracked in an issue
- [ ] Every `SKILL.md` the change adds or changes had its skill review (Phase 3a)
- [ ] An artifact skill that is new or changed has its decision in `evals/<skill>/RESULTS.md`: `adopt` after an evaluation, or `adopt (validated, not measured; derived from <anchor>)` for a derived skill. Its Performance section and the README skills table are current: `python3 evals/kpi.py doc --check`
- [ ] The version is the same in `.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json`, and is bumped for a shipped change
- [ ] `AGENTS.md` is updated when the state, layout, commands or harness change, with a change-history row; `CLAUDE.md` holds only `@AGENTS.md`
- [ ] No AI attribution, no personal paths, names or e-mail addresses in commits, pull requests, issues or files
- [ ] Topic branch `feature/<id>` or `fix/<id>`, pull request into `main` merged
- [ ] The issues the change carries are commented with the change id, closed once merged, and ticked on their tracking issue

## On Done

- Delete without asking: `_agents_workspace/**` (the scratch of every harness run), `**/__pycache__/**`, and the session's scratchpad
- Delete merged branches, locally and on the remote, and remove every worktree whose branch is merged
- Never touch: `evals/results/` (raw evaluation runs and kept deliverables)
- Never touch: `.agents/skills/openspec-*`, `.agents/skills/.openspec-target` (generated by OpenSpec)
- Do not merge pull requests: the person merges them
- An untracked `.codex/` folder or copies of harness skills under `.agents/skills/` are not this repository's: report them, never commit them (Codex is not a target)
